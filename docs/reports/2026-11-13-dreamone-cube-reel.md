# 夢想一號方塊說明型 Reel Skill 交付驗證

來源：2026 年 11 月的樣片〈4,325 京種狀態是怎麼算出來的？〉。樣片做了四版，前三輪回饋定下的規則整理成 skills/dreamone-cube-reel，樣片專案本身成為起手範本。

## 內容

- 三條不能破的規則：方塊只能由程式算出來、每顆方塊帶三角形 Logo、預設靜音。
- 版面分區與已確認的版面規則（Logo 放在安靜的地方、字幕與主體留約 95px、底部不能看起來空）。
- 文案、時間軸、方塊正確性、交付前檢查清單。
- 題材清單 11 題。
- 聲音獨立成一頁：現況、試過的四種做法、已寫好的音軌流程、需要的素材與授權、接手的人要決定的事。

範本和第三版相比的改動：預設改成靜音，句長改用字數估（每個字 0.2 秒、句中停頓 0.28 秒，由第三版試聽旁白的實際長度回推）；移除兩條沒有通過或沒有實測的配音路徑，保留「內建語音試聽」與「自備每句一檔」兩種來源。

## 實測

- Node 24、ffmpeg 8.1、HyperFrames 0.9.33，macOS。
- 從儲存庫的 `template/` 複製到一個乾淨資料夾，依序跑 `npm install`、`npm run build`、`npm run check`：
  - 方塊驗證四項全部通過（18 種基本轉動＋500 組 30 步隨機公式與 cubing.js 逐張貼紙一致；黃金測試；腳本 10 個檢查點；畫面數字）。
  - 專案檢查 0 個錯誤；3 個警告都是已知可忽略的（靜音提醒 1 個、乘法鏈小標誤判 2 個）。
  - 建置產生的 `index.html`、時間軸、字幕與畫面文字，和實際算圖用的樣片專案逐檔相同。
  - 抽 4 個時間點截圖，逐張看過。
- 靜音版成品：1080×1920、30 fps、H.264、60.4 秒、11.5 MB，只有一條視訊軌、不含音軌（ffprobe 確認）。每 5 秒抽一格做成總覽圖，逐格看過：Logo 位置、字幕與方塊的空隙、三角形 Logo、無破圖。
- 有聲模式：把 `audio` 改成 `true`，「內建語音試聽」與「自備每句一檔」兩種來源都建置成功，產生三條音軌並通過專案檢查；缺配樂檔時會停下並列出缺少的檔案。**這次沒有重新算有聲版，也沒有人聽過，聲音品質不在本次驗證範圍。**
- Skill frontmatter 驗證通過。

## 沒有驗證的

- 聲音的聽感（旁白、配樂、音效）。AI 只能量測，不能聽。
- 範本以外的題目。換題目時上方資訊區要改兩個檔，還沒有第二支影片實際走過一次。
- 其他作業系統。
