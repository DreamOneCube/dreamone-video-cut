# 方塊動畫＋真人講解 Reel Skill 交付驗證

來源：2026 年 11 月的 01〈上帝的數字 20〉。動畫由同事的 Claude 做好，講師（樹懶老師）自拍講解，合成的過程出了五版才定稿。每一輪被退回的原因和最後的做法整理成 skills/dreamone-reel-presenter。

## 內容

- 四條不能破的規則：人像不擋字幕與主體、人臉不變形、剪接點落在安靜處、交件前用量測把關並說明量不出來的事。
- 影片編號與片單（`docs/videos.md`），01 已登記。
- 十個步驟的流程：從 GitHub 拿動畫、給逐字稿、抄稿、挑取樣、對切點、接旁白與變速、重新匯出動畫、疊人像與名牌、配樂、驗收交付。
- 六支工具，以及動畫專案用的時間軸掛鉤範本。
- 18 條踩過的坑，每條附原因。

## 01 定稿的實測

- 1080×1920、30 fps、H.264、37.2 秒、14.4 MB。
- 旁白：從 204 秒的錄影挑出 11 段、併成 10 段，原速 44.7 秒，加快 1.25 倍後 35.7 秒。
- 剪接點：`snap.py` 報告 11 段全部乾淨；9 個接點的音量在 −37.9～−46.8 dB（環境底噪 −48.8 dB，講話時約 −18.6 dB）。
- 旁白回讀：十句和講師實際講的話一致，沒有多字或缺字。
- 成品回讀（墊了配樂）：十句都抄得出來；開口時間和時間軸錨點的差距在 −0.19～+0.28 秒之間。一個詞（「京種變化」）被聽錯。
- 字幕遮擋：把整支動畫疊成一張量，字幕範圍 y 1343–1500、x 111–955；圓框和名牌壓到的字幕像素都是 0，名牌離字幕 16px。
- 響度：四個配樂版本 −16.1～−16.2 LUFS、峰值 −1.3～−1.4 dBFS。
- 每隔約 3 秒抽一格做成總覽圖，逐格看過：人臉比例、圓框位置、名牌、結尾報名標籤沒有被擋。
- 配樂：四個版本由講師聽過，選了 Education Classroom Learning Flow。

## 放進 repo 的工具的實測

01 是用工具的前一版（路徑寫死在一台電腦上）做的。放進 repo 的版本改成吃參數、自己找 ffmpeg，改完之後重新跑過一次：

- 環境：macOS、ffmpeg 6.0（ffmpeg-static）、Python 3.12＋faster-whisper 1.2（small 模型）。
- **01 的原始講解素材在定稿後已經不在**，所以這次改用 01 接好的旁白當來源，另外寫一份四句的測試清單。
- `snap.py`：兩段乾淨；另外兩段故意把範圍開在句子中間，正確報出「開頭切在有聲音的地方」。
- `assemble.py`：相連的兩段有併成一段；`後停`、1.25 倍速、把錨點寫進 `timing.js`、`收框時間` 換算成 END 都正確；輸出的影像 8.833 秒、聲音 8.832 秒。
- `pip.sh`：圓框、名牌、START／END 淡入淡出正常。
- `music.sh`：成品 −16.3 LUFS、峰值 −1.4 dBFS。
- `transcribe.py --script`：三句都抄得出來。第一次跑發現講稿裡的 Markdown 粗體符號會跑進辨識結果，修正後重跑，符號不再出現。
- `probe.sh`：正常。

## 沒有驗證的

- 聲音的聽感只有 01 的四個配樂版本被聽過。配樂比人聲小 13 dB 這個值沒有被單獨確認過。
- 放進 repo 的 `snap.py` 與 `assemble.py` 沒有對「帶旋轉旗標的原始手機素材」重跑（素材已不在）。處理旋轉的那一行和做 01 時用的是同一行。
- 第二支影片。字幕位置、句數、主題配色不同的動畫還沒有走過這個流程；圓框直徑 336 是照 01 的字幕位置量出來的，換動畫要重量。
- 「從 GitHub clone 動畫專案」這一步：01 的動畫是以 zip 交付的，clone 的流程是照動畫專案自己的說明寫的，還沒實際走過。
- dreamone-cube-reel 範本做出來的動畫（寫法不同，掛鉤不能直接套）。
- 橫式素材、非 60fps 的素材。
- Skill frontmatter 沒有用驗證工具跑過，格式是比照另外兩個 skill 寫的。
