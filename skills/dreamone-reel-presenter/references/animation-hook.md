# 動畫專案的時間軸掛鉤

動畫原本的每個時間點都是寫死的秒數（第幾秒打亂、第幾秒字幕進場……）。講師錄完之後才知道每句實際講多久，要是回頭一個一個調，一支片有二三十個數字要改。

掛鉤的做法是只加一層換算：成品的第 t 秒 → 原本動畫的第幾秒。動畫本體完全不用動，方塊轉動、計數器、字幕全部跟著伸縮。

適用於「整支影片是一個 `drawFrame(t)`，給秒數就畫出那一格」的專案（01〈上帝的數字 20〉就是）。

## 接上去

1. 把 [`template/timing.js`](../template/timing.js) 複製到動畫專案的 `src/`。
2. 把裡面的 `ANCHORS_SRC` 改成這支動畫的錨點：`[0, 第 1 句字幕出現的秒數, 第 2 句……, 最後一句, 結尾秒數]`。N 句字幕有 N+2 個數字。`VOICE_ANCHORS` 保持 `null`。
3. 主程式改三個地方：

```js
// (1) 引入
import { DURATION_OUT, toSource } from './timing.js';

// (2) 成品長度改用掛鉤的值（原本是寫死的數字）
export const DURATION = DURATION_OUT;

// (3) 原本的 drawFrame 改名 drawAt，外面包一層換算
function drawAt(t) {
  // ……原本 drawFrame 的內容，一個字都不用改……
}

export function drawFrame(t) {
  drawAt(toSource(t));
}
```

預覽、拖時間軸、匯出原本都是呼叫 `drawFrame`，所以三個地方會一起生效。

4. 確認沒接壞：`VOICE_ANCHORS` 是 `null` 時，成品長度和每一格畫面都要跟接之前一模一樣。

之後 `scripts/assemble.py` 會把人聲的錨點寫進 `VOICE_ANCHORS`，重新匯出就是配合旁白的版本。要回到原速，把它改回 `null`。

## 做動畫的人可以先幫忙留的

這些不是必須，但有做的話合成那一端可以少猜：

- **右下角留給講師。** 目前定案的人像在 x 692–1040、y 1515–1912（圓框加頭上的名牌）。這一塊在人像出現期間不要放字或主體。
- **字幕不要低於 y=1500。** 人像的名牌從 y=1515 開始。
- **結尾要讓出畫面的時間點寫下來。** 例如報名標籤在第 45 秒彈出——合成時要讓人像在那之前淡出（`cuts.json` 的 `收框時間`）。
- **字幕文字集中寫在一個陣列裡**，一句一筆、有開始時間。逐字稿是從這裡整理的。

## 還沒驗證的

- dreamone-cube-reel 的範本不是 `drawFrame(t)` 這種寫法（它是 HyperFrames＋建置腳本），掛鉤不能直接套。那份範本有自己的路：把 `audio` 打開、配音來源設成「自備每句一檔」，句長會改用配音的實際長度重排時間軸。這條路還沒有拿真人錄音實際走過。
