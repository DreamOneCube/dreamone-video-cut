# 01〈上帝的數字 20〉踩過的坑

2026 年 11 月。這支片出了五版才定稿。下面每一條都是真的發生過、被講師看出來或被量測抓到的，工具已經把做法寫進去了，這裡留原因，免得之後有人把它「簡化」回去。

## 素材

**1. 人臉被壓扁。**
手機直拍的 MOV 存成 1920×1080，另外帶一個 `rotation=90` 的旗標；ffmpeg 解碼時會自動轉正成 1080×1920。接旁白時 filter 寫死 `scale=1920:1080`，等於把轉正的直式畫面又壓回橫式。
現在：一律 `scale=1080:1920`。確認方式：

```bash
ffprobe -v error -show_streams -select_streams v:0 素材.MOV | grep -i rotation
```

抽格檢查構圖時也一樣：`scale=320:180` 會壓扁，看起來像超近的大頭特寫，要用 `scale=240:-1`。

**2. 原始素材在定稿後被刪掉。**
之後想換某一句的取樣，或用原始檔重跑驗證，都做不了。
現在：素材放進該片資料夾的 `素材/`，提醒講師定稿前不要清。

## 剪接

**3. 11 個剪接點有 6 個切在有聲音的地方。**
直接拿語音辨識的字詞時間下刀。實測那些時間有 0.3～0.6 秒的誤差：句尾的字被切掉、句首的起音被削掉。
現在：辨識只用來找「哪一段講了什麼」，下刀的位置由 `snap.py` 用音量決定。

**4. 帶進上一次 NG 的尾巴。**
講師同一句連講兩次、中間沒停，辨識把第二次的開頭標在第一次的結尾裡，成品句首多了半個字。回讀的逐字稿其實有顯示，但當時沒逐字看。
現在：`snap.py` 會標出「範圍一開始就有聲音」；回讀要逐字對。

**5. 每個接點都有小頓點。**
每一段各自壓成 AAC 再用 concat 串起來。AAC 每段開頭會多墊約 21 毫秒，十個接點就是十個空隙。
現在：聲音全程用 WAV 接，最後才壓一次；每個接點加 12 毫秒淡入淡出。

**6. 聲音愈來愈晚。**
用 `-ss` 剪 HEVC，每段實際長度會比指定的多一點，一路累積到結尾差了 1.35 秒；而時間軸是照「指定的長度」算的。
現在：每段剪出來先數格數，聲音照實測長度去切，時間軸也用實測值算。

**7. 補的停頓不見了。**
`-t` 放在 `-i` 後面是限制輸出長度，會把 `tpad` 補的定格一起切掉。
現在：`-t` 放在 `-i` 前面。

**8. 加速後句尾黏到下一句。**
1.25 倍速之後兩句只隔 0.15 秒，「二十步」的「步」聽起來像下一句「不過」的開頭。
現在：在前一句加 `"後停": 0.3`。

## 人像

**9. 圓框擋到動畫、又擋到文字。**
動畫把畫面從 y=160 用到 y=1576，中間沒有空角落。用眼睛估「應該沒擋到」，結果直徑 420 的圓框壓到 3,837 個字幕像素。
現在：把整支動畫疊成一張圖來量（SKILL.md 第 8 節），壓到的字幕像素要是 0。

**10. 看不到手勢。**
直式素材從頭頂到手佔滿整個高度，正方形裁切不是切頭就是切手。
現在：`FIT=contain`，整張塞進圓裡，兩側用放大模糊的同一張補滿。講師背景是素色時幾乎看不出來。

**11. 圓框蓋住結尾的報名標籤。**
標籤在講師還沒講完 CTA 時就彈出來。
現在：`cuts.json` 填 `收框時間`，圓框在那之前淡出，聲音照常。

**12. 名牌放錯邊。**
先放在圓框下緣，講師要的是頭的上面。上緣離字幕只有 28px，所以圓框從 360 縮到 336、往下貼到 1912，才讓得出位置。

## 聲音

**13. 成品峰值超過標準。**
限幅器設在 −1 dBFS，但 AAC 壓縮後會過衝 0.1～0.3 dB。
現在：限幅器設在 −1.5 dBFS。

**14. 講稿的 Markdown 符號汙染辨識結果。**
把含 `**粗體**` 的逐字稿當提示餵給辨識器，輸出也跟著冒出 `**`。
現在：`transcribe.py --script` 會先把符號拿掉。

## 環境

**15. faster-whisper 裝不起來。**
系統的 Python 是 3.15，`av` 還沒有對應的輪子，要從原始碼編，又缺 pkg-config。
現在：用 `uv` 另外帶一個 Python 3.12 的虛擬環境（README 有指令）。

**16. `drawtext` 找不到字型。**
ffmpeg-static 的版本沒有 fontconfig。
現在：一律寫 `fontfile=`，用 dreamone-cube-reel 附的粉圓體。

## 流程

**17. 要求講師「每句之間停頓半秒」，結果沒人這樣講話。**
原本想靠停頓切句子。實際錄影是 204 秒連續講、每句試好幾次，靠停頓完全切不出來。
現在：不對講師的講法提要求，用語音辨識找句子。

**18. 動畫的修改只留在一台電腦上。**
動畫是透過雲端硬碟的 zip 交的，這邊加的時間軸掛鉤回不去，下一支又要重加。
現在：動畫走 GitHub，掛鉤的範本放在 `template/timing.js`。
