## 版面分區

| y 範圍 | 內容 |
|---|---|
| 0–168 | 空（系統列） |
| 168–231 | Logo（彩色橫式原檔縮圖），左上角，下方 100px 以上不放東西 |
| 345–610 | 上方資訊：開場標題 → 6／8／12 → 算式與乘法鏈 → 答案 → 結尾大數字 |
| 約 607–1225 | 方塊（寬約 540px，中心約 y 915） |
| 1312–1490 | 字幕（逐句，最多兩行），和方塊之間留約 95px，右側避開 IG 按鈕 |

## 檔案與改法

| 要改什麼 | 改哪裡 |
|---|---|
| 稿子、字幕、每句停多久、要不要聲音 | `lib/script.js` |
| 方塊動作、畫面數字、事件時間點 | `lib/reel-data.js` |
| 上方資訊區放什麼 | `tools/build.mjs` 第 4 段的 `top` 清單 |
| 版面與字級 | `tools/words.template.html`、`tools/captions.template.html` |
| 方塊外觀、鏡頭、燈光 | `compositions/cube.html` |

改完跑 `npm run build`（會重排時間軸、重產字幕與畫面文字，最後自動跑方塊驗證），再 `npm run render`。
`index.html`、`compositions/words.html`、`compositions/captions.html`、`lib/timing.js` 都是產生出來的，不要手改。
