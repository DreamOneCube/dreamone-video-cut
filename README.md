## 影片剪輯

- [dreamone-video-cut](skills/dreamone-video-cut/SKILL.md)：選 take、保守跳剪、章節與可切換版面、統一音量、SRT／TXT 字幕。不限《大師不藏私》或斜轉。
- 短影片：剪停頓與發語詞、單行燒入字幕、重點詞上色放大、資訊卡、B-roll、三角形 Logo（[SKILL.md 第 10 節](skills/dreamone-video-cut/SKILL.md)）
